Student Task Manager

Student Task Manager is a task management application designed for students to organize and manage their daily tasks. Users can create, update, delete, and track tasks and receive notifications before tasks become overdue.

Features:
Create and manage tasks
Update and delete tasks
Track task status
Set task due dates
Receive notifications before tasks become overdue
User authentication
Simple and user-friendly interface

How It Works:
Users create an account and log in.
Users add tasks with their details and due dates.
Tasks can be updated or deleted when needed.
Users can track their task status.
Notifications are sent before a task becomes overdue.
Users can manage their tasks and stay updated on upcoming deadlines.

Technologies Used:
React.js
Node.js
Express.js
MongoDB
JavaScript

Project Type:
Individual Project
